# Database 

## Описание
В данной директории содержатся файлы для работы с базой данных проекта “Testing System”.

## Структура
* schema.sql — создание структуры базы данных (таблицы, связи, ограничения)
* seed.sql — заполнение базы тестовыми данными

## Как запустить
1. Создать базу данных и выбрать ее:
```bash
CREATE DATABASE testing_system;
USE testing_system;
```

2. Выполнить код schema.sql:
* открыть файл в MySQL Workbench
* Нажать кнопку Execute

3. Выполнить код seed.sql:
* открыть файл в MySQL Workbench
* Нажать кнопку Execute

## Особенности БД
1. Используется реляционная база данных MySQL
2. Реализованы связи между таблицами через FOREIGN KEY
3. Поддерживаются различные типы вопросов:
    * single (один ответ)
    * multiple (несколько ответов)
    * text (текстовый ответ)
4. Таблица user_answers поддерживает multiple-ответы:
    * допускается несколько записей на один вопрос
	* исключаются дубликаты одинаковых ответов

## Назначение
База данных используется для:
* хранения пользователей
* хранения тестов и вопросов
* записи попыток прохождения тестов
* хранения ответов пользователей
* расчета результатов тестирования
