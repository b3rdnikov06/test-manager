# Test Manager

## Описание проекта
Веб-приложение для проведения онлайн-тестирования студентов. Позволяет преподавателям создавать тесты и анализировать результаты, а пользователям — проходить тестирование и получать результаты.

## Основной функционал

### Для студентов
- Регистрация и авторизация
- Просмотр доступных тестов
- Прохождение тестирования
- Получение результатов
- Просмотр истории прохождений

### Для преподавателей
- Создание и редактирование тестов
- Управление вопросами и ответами
- Публикация тестов
- Просмотр результатов студентов
- Аналитика попыток прохождения

---

## Базовые бизнес-правила

- Тест должен содержать от 5 до 20 вопросов
- Закрытые вопросы должны содержать минимум 2 варианта ответа
- Вопрос типа single может иметь только один правильный ответ
- После публикации запрещено изменение структуры теста
- Один студент может иметь только одну попытку прохождения теста
- Время прохождения теста ограничивается преподавателем (от 5 до 30 минут)

---

## Роли пользователей

### Student
- Прохождение тестов
- Просмотр результатов
- Просмотр собственной статистики

### Teacher
- Создание тестов
- Управление тестами
- Просмотр результатов всех пользователей
