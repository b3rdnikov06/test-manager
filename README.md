# test-manager

## Описание проекта
Веб-приложение для проведения онлайн-тестирования студентов. Позволяет преподавателям создавать тесты и анализировать результаты, а пользователям — проходить тестирование и получать результаты.

## Основной функционал
    * Регистрация и авторизация пользователей
    * Создание и управление тестами
    * Прохождение тестов
    * Автоматическая проверка результатов
    * Хранение истории и аналитика

## Роли пользователей
    * Student — прохождение тестов, просмотр результатов
    * Teacher — создание тестов, управление результатами

## Технологии
    * Frontend: React
    * Backend: Node.js
    * Database: MySQL
