# Тест-кейсы для тестирования прохождения тестов

---------------------------------------------------
ID: ATTEMPTS-01
Название: успешное создание попытки прохождения теста

Предусловие:
- тест с вопросами существует.

Шаги:
1. Отправить POST /attempts/start с валидными данными

Тестовые данные:
``` json
{
  "user_id": 1,
  "test_id": 1
}
```

Ожидаемый результат:
- 200 OK
- в response body присутствует сообщение "Attempt started"
- в таблице attempts создаётся новая запись с указанными user_id и test_id, a также started_at
- все данные в полях таблиц корректны и соотвествуют своему типу

ID: ATTEMPTS-05
Название: отправка правильных ответов на вопрос типа single и завершение теста

Предусловие:
- тест начат

Шаги:
1. Отправить POST /attempts/{attempt_id}/answer с правильным ответом на существующий вопрос
2. Отправить POST /attempts/{attempt_id}/submit

Тестовые данные для запроса POST /attempts/{attempt_id}/answer:
``` json
{
  "question_id": 1,
  "answer_id": 1
}
```

Ожидаемый результат:
- 200 OK
- в response body присутствует сообщение "Test completed", score = 1, total = 3, percentage = 33
- в таблице attempts изменяется уже существующая запись: добавляется поле finished_at
- в таблице results создаётся новая запись с указанным attempt_id, а также score и max_score
- все данные в полях таблиц корректны и соотвествуют своему типу
